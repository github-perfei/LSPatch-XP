# 验收清单（真车）

- [ ] 改签包能安装、能打开、能登录账号
- [ ] 数字钥匙可激活 / 钥匙检查通过
- [ ] 「靠近自动解锁」「离开自动闭锁」开关可见且能保存
- [ ] SpoofMyDevice 作用域仅绑定小鹏，Safe Mode 开启（不改假 Android 版本）

- [ ] 离开能上锁（注意背包/身体遮挡会导致测距飘）
- [ ] 重启手机后：按你的习惯打开一次 App 或确认自启动后仍可用
- [ ] 已关闭该 App 自动更新；物理钥匙可应急

异常时优先查：权限/后台 > 蓝牙开关 > Spoof 是否仍绑定 > 是否被系统更新覆盖回官方包。
